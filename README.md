# مكتبة الظلال — فهرس التحديثات العام

هذا المستودع العام يحتوي **بيانات الإصدارات الجديدة فقط**، ولا يحتوي كود تطبيق أندرويد أو مفاتيح توقيع أو بيانات خاصة.

## رابط الفهرس المباشر
```text
https://raw.githubusercontent.com/jassimjhq1-art/shadow-library-feed/main/catalog.json
```

### تفعيل الفهرس في تطبيق أندرويد المثبّت (مرة واحدة)
1. افتح «مكتبة الظلال» ← «الإعدادات».
2. الصق الرابط أعلاه في «رابط فهرس المكتبة (HTTPS)».
3. اضغط **حفظ الرابط**، ثم **تحقق من التحديثات**.
4. إذا ظهر «مكتبتك محدّثة بالفعل»، الاتصال سليم، وما فيه كتب جديدة منشورة إلى الآن.
5. بعد النشر، يتحقق التطبيق من الفهرس عند فتحه، ويستطيع عرض إصدارات جديدة دون إعادة تثبيت APK.

**الفهرس الحالي**: `revision: 1`, و`books: []` — إعداد مبدئي، لا يضيف قصصاً وهمية.

## إضافة كتاب جديد
عدّل `catalog.json` وارفع رقم `revision`، مع إضافة كائن كتاب جديد في `books`.
مثال لبنية كتاب جديد (المحتوى التالي قالب توضيحي وليس كتاباً منشوراً):

```json
{
  "version": 1,
  "revision": 2,
  "books": [
    {
      "id": "book_02",
      "title": "عنوان الكتاب الجديد",
      "subtitle": "وصف مختصر",
      "description": "مقدمة الكتاب",
      "cover": null,
      "chapters": [
        {
          "title": "عنوان الفصل",
          "category": "crime",
          "eyebrow": "ملف تحقيق",
          "minutes": null,
          "audio": null,
          "paragraphs": [
            {"t": "h2", "text": "بداية الملف"},
            {"t": "p", "text": "اكتب هنا نص الفصل الحقيقي المراجَع."}
          ]
        }
      ]
    }
  ]
}
```

الأنواع المتاحة: `horror`, `crime`, `heist`, `prison`. استخدم روابط `https://` للصور والأصوات. يجب التأكد من الحقوق والمصادر قبل نشر المحتوى.

### صوت الفصل العاشر من الكتاب الأول
عندما يجهز التسجيل يمكن إضافة كائن `{"id":"nightmare","chapters":[{"id":10,"audio":"https://...mp3","minutes":12}]}` ضمن `books` بدل إنشاء نسخة مكررة من الكتاب. الرابط يجب أن يكون حقيقياً.

## فحص النشر
GitHub Actions يشغّل `scripts/verify_feed.py` بعد كل تغيير على الفهرس. فتح `catalog.json` لا يحتاج حساباً أو مفتاحاً سرياً.

## حدود النسخة الحالية
- هذا الفهرس يحدّث **المحتوى** ولا يثبّت تحديثات APK أو يغيّر كود التطبيق.
- النسخة الأولى تضيف كتباً جديدة، وتستطيع تحديث رابط الصوت لفصول الكتاب الأساسي. تغيير نصوص الكتب المنشورة أو حذفها يتطلب تطوير مزامنة أكثر اكتمالاً في إصدار لاحق.
- المستودع البرمجي الأصلي **خاص** باسم `shadow-library-android`. لا تنشر مفاتيح التوقيع هنا.
